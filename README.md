# everyPilot community

everyPilot is a pilot logbook you pay for once, with no subscription. Your records stay on your phone and in the cloud account *you* choose. We never hold them.

The app is shaped by the pilots who use it. This is where you tell us what to build next.

## How to take part

| You want to… | Go here |
|---|---|
| Suggest a feature | [Ideas → New idea](https://github.com/everyAi007/everypilot-community/discussions/new?category=ideas) |
| Vote on what gets built | [Ideas](https://github.com/everyAi007/everypilot-community/discussions/categories/ideas): upvote the ones you want |
| Report a problem | [Report a problem](https://github.com/everyAi007/everypilot-community/issues/new?template=bug_report.yml) |
| Ask how to do something | [Q&A](https://github.com/everyAi007/everypilot-community/discussions/categories/q-a) |
| See what's new | [Announcements](https://github.com/everyAi007/everypilot-community/discussions/categories/announcements) |

You can open all of these from the app too: **Me → Community**.

## How ideas get picked

1. Every idea gets read.
2. The most upvoted ideas go to the top of the list.
3. When an idea is planned, it gets the **Planned** label. When it ships, it's marked **Shipped** and linked from the release notes.

## Ground rules

- Never post logbook data, licence numbers, medical details or anything personal. A screenshot with names blurred out is fine.
- One idea per post. Search first and upvote if it already exists.
- Be kind. We're all pilots here.
